Welcome to my blog! This is my first post using Hexo and Fluid theme.

## About this blog

This is a personal blog where I'll share my thoughts, experiences, and technical knowledge. I'm excited to start this journey and hope you'll find something interesting here.

## Features

- Beautiful and responsive design
- Dark mode support
- Reading progress indicator
- Code highlighting
- Image lightbox
- Math formula support
- And many more!

## Getting started

To create a new post, run:

```bash
hexo new "Your Post Title"
```

To start the development server:

```bash
hexo server
```

Happy blogging! 🎉
